## PYTHON EMAIL SLICERS PROJECT
--A Biginner-friendly python project that extract the username and domain from an email address.

## FEATURES
--Accept an email address from the user.
--Extracts the username.
--Extracts the domain name.
--Display results clearly

## TECNOLOGIES USED
--Python 3.
--Pycharm as a code editor.
--Git as a version control.
--GitHub as a code hosting.

## EXAMPLE
**Input
--Enter your email address:nasir143@gmail.come
**Output
--username:nasir143
--domain:@gmail.com

## HOW TO RUN
-1.Clone this repository
--git clone https://github.com/abdinasir703/EMAIL-SILCERS-PROJECT.git

-2.Navigate to the project folder:
--cd email-slicer

-3.Run the program
--python main.py
